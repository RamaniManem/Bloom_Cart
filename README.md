# 🌷 BloomCart — Flower Boutique Website

**BloomCart** is a flower boutique website designed to make discovering and creating beautiful floral arrangements a delightful experience.

The project features an elegant floral theme, a collection of flowers, a custom bouquet builder, ready-made bouquets, and an interactive shopping cart.

## ✨ Features

- 🌹 **Flower Collection:** Browse a catalogue of 30 flower products.
- 🔍 **Search and Filters:** Find flowers by name, type, or colour.
- ↕️ **Sorting:** Arrange products by price or name.
- ❤️ **Wishlist:** Save favourite flowers.
- 🛒 **Shopping Cart:** Add products, update quantities, and remove items.
- 💐 **Custom Bouquet Builder:** Select flowers and quantities to create a personalised bouquet.
- 🎁 **Ready-Made Bouquets:** Explore pre-designed floral arrangements.
- 📱 **Responsive Navigation:** Includes a mobile navigation menu.
- ✉️ **Newsletter Interface:** Demonstrates a newsletter subscription form.
- 🔔 **Toast Notifications:** Receive feedback when interacting with website features.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Unsplash image URLs for flower photography

## 🎨 Design

BloomCart uses a floral boutique aesthetic with an elegant, nature-inspired interface.

The website focuses on presenting flower products clearly and making browsing, bouquet customisation, and cart interactions easy to understand.

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server or another local web server.
4. Explore the flower catalogue and test the available features.

No backend server or package installation is required for the current frontend demo.

## 🌐 Deployment

BloomCart can be deployed as a static website using Vercel.

Once deployed, the website can be accessed through a public URL.

## ⚠️ Project Notes

- Product prices are illustrative demo prices in Indian rupees.
- The shopping cart is currently maintained in browser memory and does not persist after refreshing the page.
- The newsletter form is a demonstration and does not store email addresses.
- Product photographs are loaded from external image URLs, so an internet connection is needed to display them.
- The project does not currently include a payment gateway or backend order-processing system.
